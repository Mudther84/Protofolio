Library Management System

Technologies: Java 8, Object-Oriented Analysis & Design (OOAD), Console-Based UI, Apache Derby (Java DB), NetBeans. Description: Developed a full-featured, console-driven Library Management System as part of a university OOAD course. Implemented core library workflows including book search (by title, author, subject), placing holds, check-in/check-out, renewals, fine management, and user role administration. Designed with strict adherence to OOP principles—achieving high cohesion and low coupling—and decoupled entities to minimize GUI dependency.
